# Estudos práticos de Python

Coleção de exercícios desenvolvidos durante meus estudos de **Python, lógica de programação, orientação a objetos, visualização de dados e SQLite**.

Este repositório registra minha evolução técnica e apresenta exemplos pequenos, executáveis e documentados. Todos os dados utilizados são fictícios.

## Conteúdo

| Arquivo | Conceitos praticados |
| --- | --- |
| `dados.py` | SQLite, funções, consultas parametrizadas e organização de código |
| `bibli.py` | Classes, listas, agregação de dados e matplotlib |
| `Exercicio_Filme.py` | Laços, validação de entrada e tratamento de erros |
| `Funcoes.py` | Funções, retorno de valores e cálculo de média |
| `Python.py` | Condicionais e cálculo de média |
| `Faculdade.py` | Exercícios introdutórios com estruturas condicionais |

## Como executar

### Pré-requisitos

- Python 3.10 ou superior
- matplotlib, apenas para o exemplo da biblioteca

### Instalação

```bash
git clone https://github.com/Guilherme9639/Python.git
cd Python
python -m venv .venv
```

No Windows:

```powershell
.venv\Scripts\Activate.ps1
pip install matplotlib
```

Execute um exemplo:

```bash
python dados.py
```

O arquivo de banco `contatos.db` é criado localmente durante a execução e não deve ser versionado.
